# 16º Festival Hercule Florence · 2026

Site oficial da XVI edição do Festival Hercule Florence de Fotografia, Campinas, 5 a 23 de agosto de 2026.

Este repositório é a fonte do site publicado em https://festivalherculeflorence.com.br/. Todo commit em `main` é publicado automaticamente na hospedagem (HostGator) via GitHub Actions (`.github/workflows/deploy.yml`), que sincroniza os arquivos deste repositório para `public_html` por FTP.

O WordPress anterior foi movido para `public_html/_wp-antigo` na hospedagem, como backup, e não está mais no ar.
